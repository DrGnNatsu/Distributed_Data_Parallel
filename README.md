# Distributed Data Parallel

This is a simple implementation of Distributed Data Parallel (DDP) in PyTorch. DDP is a technique for training
deep learning (DL) models across multiple GPUs and nodes, allowing for faster training and better utilization of resources.

Author: This is my own self-learn path to understand DDP in PyTorch.
I have implemented this code to learn and understand the concepts of DDP.

## Installation

To install the required dependencies, you can use pip:

```bash
# Init the python environment through uv
uv init
# Create the python environment through uv
uv venv
# Activate the python environment through uv
uv activate
# Install the required dependencies
uv sync
# OR you can install by your own way (CUDA version can be changed according to your GPU)
uv pip install torch --index-url https://download.pytorch.org/whl/cu124
```

## Usage

To use the Distributed Data Parallel (DDP) implementation, follow these steps:

1. Initialize the Python environment using `uv init`.
2. Create a virtual environment using `uv venv`.
3. Activate the virtual environment using `uv activate`.
4. Install the required dependencies using `uv sync` or `uv pip install torch --index-url https://download.pytorch.org/whl/cu124`.
